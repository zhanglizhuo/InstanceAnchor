========================================================================
  Interpretation
========================================================================
  ⚠ Weak correlation between visual anchoring and CLIP recall.

  Key findings:
  1. Visual anchoring (MLLM crop-level annotation accuracy) and CLIP
     per-class recall show NO significant correlation (ρ=-0.23, p=0.16).
     This means MLLM and CLIP fail for DIFFERENT reasons.
  2. MLLM fails on intent-dependent classes (answer, guide, on-stage
     interaction → 0% annotation accuracy) because single-frame crops
     cannot convey teaching intent.
  3. CLIP fails on visually-confusable classes (blackboard-writing →
     misclassified as screen/teacher) because full-image embedding
     cannot separate co-occurring visual elements without training.
  4. Classes where BOTH fail (answer, guide): need temporal context.
     Classes where CLIP > MLLM (stand, guide): CLIP benefits from
     full-image context that MLLM crops miss.
     Classes where MLLM > CLIP (blackboard-writing): crop-level focus
     isolates the relevant visual signal better than full-image CLIP.
  5. Practical implication: NEITHER approach alone suffices. A hybrid
     pipeline needs (a) CLIP+CAPE for action-recognition classes,
     (b) MLLM crop-level annotation for visually-distinctive classes,
     and (c) temporal context (video) for intent-dependent classes.
